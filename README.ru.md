`dsh-skill-market` добавляет в боковую панель панель **Skill Market**, превращая библиотеку навыков SkillHub в место, где можно просматривать, фильтровать, искать, смотреть детали и **устанавливать на эту машину в один клик**. Установленный навык ничем не отличается от написанного вручную локального навыка: собственная система навыков Harness обнаруживает их как обычно, и их можно вызывать в любом сеансе.

> **Навыки созданы не этим плагином.** Каждый навык, перечисленный в панели, взят с [SkillHub](https://skillhub.cn), создан и опубликован своим автором, **авторские права принадлежат первоначальным авторам**, и каждый навык регулируется заявленной им лицензией. Этот плагин лишь помогает удобнее находить и устанавливать их внутри Harness.

- **Обзор (Discover)** — вся библиотека навыков SkillHub, по умолчанию сортировка по количеству загрузок. Фильтры по категориям, поиск по ключевым словам, ленивая загрузка, установка прямо с карточки.
- **Установленные** — навыки на этой машине. Можно **отключить без удаления** (каталог перемещается в зону отключённых, и Harness его больше не видит), а также обновить или удалить.
- **Избранное** — список избранного хранится только на этой машине, чтобы отмечать навыки, которые хочется установить.
- **Локальный импорт** — перетащите свой пакет навыка `.zip` или просто скопируйте папку в каталог навыков.
- **Выдвижная панель деталей** — шесть вкладок: обзор, файлы, история версий, права доступа, сканирование безопасности, метрики. Вкладка файлов раскрывает настоящее дерево файлов и показывает содержимое, а из истории версий можно установить любую старую версию.

## Установка

### Установка из интерфейса Harness (рекомендуется)

Откройте **DeepSeek Harness → Плагины → Добавить плагин** и введите имя пакета npm:

```text
@montersy123/dsh-skill-market
```

Нажмите **Установить**. Код в пакете — это уже готовый к запуску ESM, **никакой сборки не требуется**. Этот же диалог принимает адрес репозитория GitHub и путь к локальному каталогу.

</p>

### Установка через командную строку `dsh`

Выберите профиль по тому, в каком виде вы запускаете DSH. **Десктопная версия** — `desktop`, **веб-версия** — `web`:

```sh
# Веб-версия
dsh plugin --profile web add @montersy123/dsh-skill-market

# Десктопная версия
dsh plugin --profile desktop add @montersy123/dsh-skill-market
```

Обе команды устанавливают из **официального реестра npm** и дают опубликованную версию. Чтобы использовать ещё не опубликованный коммит из `main` репозитория, замените имя пакета на `github:montersy123/dsh-skill-market` — pnpm закрепит git-зависимость за тем единственным коммитом, до которого она разрешилась, и при последующих обновлениях её придётся разрешать заново, поэтому для обычной установки имя пакета удобнее.

`dsh plugin` передаёт операции управления пакетами в pnpm, поэтому разница между `web` и `desktop` только в том, в какой профиль произойдёт установка. **Сначала убедитесь, что pnpm есть в PATH.**

После установки **перезапустите соответствующую форму**, чтобы новый слой bundle вступил в силу:

```sh
dsh --profile web
```

Чтобы убедиться, что этот слой действительно загрузился, можно перед запуском один раз вывести конфигурацию дампом; в выводе должна появиться строка `# == @montersy123/dsh-skill-market`:

```sh
dsh --profile web --dump-config
```

### Установка из локального каталога

Если репозиторий уже клонирован, просто укажите этот каталог (имена профилей те же, что выше):

```sh
dsh plugin --profile web add ./dsh-skill-market
```

### Обновление

Установленные плагины не обновляются автоматически. Просто выполните ту же команду установки ещё раз — запись по имени пакета разрешается по семантическому версионированию (в отличие от git-зависимости, закреплённой за конкретным коммитом). Установленные навыки, состояние отключения и избранное сохранятся (состояние хранится вне пакета).

### Где хранятся мои данные

Все данные плагина находятся **целиком** в собственном каталоге storages DSH (там же, где реестр `dsh-cost-meter`), не записываются ни в профиль, ни в хранилище сеансов самого DSH:

```
$DSH_HOME/storages/@montersy123/dsh-skill-market/data/
├── panel.json        избранное (с полными записями навыков), реестр установленных, предпочтения категорий, подсказки о перезапуске
├── installed.json    какая версия каждого навыка установлена
└── skills/           отключённые навыки (каталог целиком перемещается сюда, и Harness его больше не видит)
```

Включённые навыки находятся не в этом каталоге, а в собственном корне навыков Harness — `$DSH_HOME/skills`; переключатель в панели именно перемещает каталог между этими двумя местами, поэтому «включено/отключено» — это местоположение, а не отметка.

По умолчанию `$DSH_HOME` — это `%USERPROFILE%\.dsh` (можно переопределить переменной окружения). Для резервного копирования или миграции скопируйте этот каталог `data`; чтобы полностью всё очистить, удалите его (установленные навыки находятся отдельно, в `$DSH_HOME/skills`).

> Это место менялось несколько раз: более ранние версии хранили состояние панели в **Local Storage** страницы (собственный `%APPDATA%\@deepseek-ai\dsh-desktop\Local Storage` десктопной версии DSH, в одном хранилище с остальными плагинами), позже оно переехало в `@montersy123-dsh-skill-market/data` внутри каталога профиля. **Текущая версия читает только `$DSH_HOME/storages/...` и не совместима со старыми местами**: при обновлении со старой версии перенесите старый каталог `data` целиком в новое место; если не перенести, всё начнётся с нуля.

**После установки навыка нужно перезапустить DeepSeek Harness**: файлы навыка сразу попадают на диск, но разговор использует список навыков, определённый в момент его начала, поэтому вновь установленный навык можно вызывать только в **новом сеансе**. Панель объясняет это полосой подсказки и всплывающим сообщением (toast) и при этом не блокирует никакие элементы управления: можно изменить сразу несколько навыков, а потом перезапуститься один раз.

## Использование

| Место | Что вы получаете |
| --- | --- |
| **Обзор** | Вся библиотека SkillHub: chips категорий показывают по каждой категории **общее количество**, поиск работает по ключевым словам, на карточках отображаются загрузки, рейтинг, число добавлений в избранное и отметки безопасности. |
| **Установленные** | Каждый навык из библиотеки: источник, версия, каталог, количество файлов, время установки, а также переключатель включения/отключения и обновление/удаление. |
| **Избранное** | Список избранного только на этой машине, с установкой в один клик. |
| **Локальный импорт** | Перетаскивание `.zip` или помещение каталога прямо в каталог навыков — оба способа попадут в список с указанием, какой именно. |
| **Выдвижная панель деталей** | Шесть вкладок. Вкладка **сканирования безопасности** перечисляет выводы каждого стороннего проверяющего по отдельности. |

### Выдвижная панель деталей

Нажмите на любую карточку, чтобы открыть её. Вверху — полоса статистики: загрузки, добавления в избранное, сводный рейтинг, версия; ниже — шесть вкладок. На скриншоте в начале страницы эта панель раскрыта справа.

**Обзор** даёт описание от вышестоящего источника и ключевую информацию; **Файлы** раскрывают настоящее дерево каталогов, а отдельный файл можно открыть и просмотреть; **История версий** перечисляет примечания к каждому выпуску и позволяет установить любую старую версию обратно; **Права доступа** различают декларации самого навыка и поведение этого плагина; **Метрики** — это исходные цифры SkillHub.

### Что на самом деле делает «Установка»

Навык действительно скачивается, распаковывается и записывается в `$DSH_HOME/skills/<handle>--<slug>/`. Это **собственный** корневой каталог навыков Harness, а не приватный каталог плагина — именно поэтому установленный навык становится обычным локальным навыком: встроенный провайдер файловой системы обнаруживает его, в списке навыков он стоит рядом с написанными вручную, и **отключение этого плагина не заставит его исчезнуть**.

**«Отключено» — это местоположение, а не отметка.** Включение и отключение перемещают каталог между двумя корневыми каталогами, поэтому положение на диске всегда является фактом. Это также означает, что можно сделать это вручную: скопируйте папку в `$DSH_HOME/skills` — навык включён; скопируйте в зону отключённых — навык отключён; панель признаёт оба варианта.

### Сканирование безопасности

SkillHub сканирует каждый навык несколькими сторонними проверяющими. **Панель показывает зелёную отметку «Безопасно» только тогда, когда все проверяющие сообщают о безопасности**: на практике проверяющие часто противоречат друг другу, поэтому, если хотя бы один считает навык подозрительным, не показывается никакая отметка (а не серая). Отсутствие отметки честно означает «вывода нет», а серый chip создал бы впечатление, что у панели есть собственное суждение.

Вкладка сканирования безопасности построчно перечисляет вывод и ссылку на отчёт каждого проверяющего, поэтому разногласия видны, а не сжимаются в один вывод.

## Язык

Интерфейс **двуязычный (китайский и английский)** и следует языковой настройке самого DSH в **Настройки → Общие**; в панели нет второго переключателя. Все строки интерфейса существуют в двух вариантах, а числа и даты форматируются по текущему языку.

## Требования к окружению

- DeepSeek Harness с доступным деревом клиентских плагинов (этот плагин — bundle: манифест `dsh.bundle` + слой `cordis.patch.yml`).
- Node.js на стороне Host **>= 20**.
- Сетевой доступ к `api.skillhub.cn`. Он нужен для просмотра и установки; включение, отключение и удаление его не требуют.

## Примечания

- **Не трогает ваши данные.** Ни `$DSH_HOME/skills`, ни `data/` плагина не очищаются при запуске; отключённые и импортированные навыки сохраняются и после перезапуска, и после обновления плагина.
- **Подтверждение запрашивается только для разрушительных операций.** Установка и обновление не вызывают подтверждения, а **удаление** и **откат версии** вызывают: они удаляют каталог, и для восстановления придётся скачивать заново.
- **Нет числа — число не показывается.** Отсутствующее количество загрузок не отображается как `0`: так выглядит «не измерено», а напечатанное оно становится фактом, который никто не измерял.
- **Пакет, сам по себе не соответствующий требованиям, отклоняется при установке.** Реестр проверяет поле `name` только **при загрузке** навыка, поэтому пакет, заявивший `name: Something With Spaces`, тихо установился бы и никогда не появился. Теперь такие пакеты отклоняются при установке с указанием на ошибку издателя.
